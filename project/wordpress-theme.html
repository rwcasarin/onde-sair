Como functions.php pensa

Trecho real do tema: registro do CPT Lugar + taxonomia Afinidade com slug raiz vazio (URLs sem prefixo).

functions.php · trecho
// CPT Lugar
register_post_type( 'lugar', [
    'public'      => true,
    'has_archive' => 'lugares',
    'rewrite'     => [ 'slug' => 'lugar' ],
    'supports'    => [ 'title', 'editor', 'thumbnail' ],
    'menu_icon'   => 'dashicons-location',
] );

// Taxonomia Afinidade · slug raiz vazio = URLs limpas
register_taxonomy( 'afinidade', [ 'lugar', 'roteiro' ], [
    'public'       => true,
    'hierarchical' => false,
    'rewrite'      => [ 'slug' => '', 'with_front' => false ],
] );

// /para-dates  →  taxonomy-afinidade.php  →  lista de lugares dessa afinidade

Instalar em 6 passos

Funciona em qualquer WordPress 6.0+. Sem dependência de plugin.

1
Zipa a pasta theme/onde-sair/ como onde-sair.zip.
2
No WP: Aparência → Temas → Adicionar nova → Enviar tema. Faz upload do zip e ativa.
3
Vai em Configurações → Links permanentes, escolhe "Nome do post" e clica Salvar. (Isso regenera as rewrites das taxonomias.)
4
Em Lugares → Afinidades, cria os 6 termos com slugs: para-dates, para-impressionar, para-turistar, para-relaxar, para-economizar, para-a-criancada.
5
Em Lugares → Tipos, cria: restaurantes, bares, parques, shows-e-baladas, eventos.
6
Cria 5–10 Lugares e 2–3 Roteiros de teste. Define uma página estática como Home em Configurações → Leitura. Pronto.
